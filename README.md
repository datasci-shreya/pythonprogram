# Trader Performance vs Market Sentiment

## Objective
The objective of this project is to analyze the relationship between
market sentiment (Fear & Greed Index) and trader performance.

## Datasets Used
- Historical Trader Data (Hyperliquid)
- Fear & Greed Index

## What I Did
- Loaded Historical Trader Data and Fear & Greed Index datasets
- Cleaned the data and handled missing values
- Converted timestamps to date format
- Merged both datasets using date
- Calculated trader performance using Closed PnL
- Grouped traders into Frequent and Infrequent traders
- Compared trader behavior during Fear and Greed days

## Key Insights
- Trader performance changes based on market sentiment
- Frequent traders perform better during Greed days
- Infrequent traders show higher losses during Fear days

## Strategy Recommendations
- During Greed days, active traders can increase trade frequency
- During Fear days, traders should reduce leverage and trade cautiously

## Conclusion
Market sentiment has a strong impact on trader behavior and performance.
Understanding sentiment can help in making better trading decisions.
